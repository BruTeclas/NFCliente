# Marca NFCliente

Logo "Chaveiro NFC" (v1.7.7): um chaveiro com as ondas de aproximação e o nome com "NFC" destacado.

## Arquivos

| Arquivo | Uso |
|---|---|
| `nfcliente-logo.svg` / `.png` | Logo horizontal para fundo claro |
| `nfcliente-logo-escuro.svg` / `.png` | Logo horizontal para fundo escuro |
| `nfcliente-vertical.svg` / `.png` | Logo empilhada (ícone em cima), para fundo claro |
| `nfcliente-vertical-escuro.svg` | Logo empilhada para fundo escuro |
| `nfcliente-icone.svg`, `-512.png`, `-1024.png` | Só o ícone, com fundo transparente |
| `nfcliente-icone-quadrado.svg` | Ícone sem cantos arredondados (o celular arredonda sozinho) |
| `perfil-redes-sociais.png` | Foto de perfil do Instagram, WhatsApp e Facebook (1080 × 1080) |

Para impressão (adesivo, cartão, embalagem), prefira os arquivos `.svg`: são vetoriais e não perdem qualidade em nenhum tamanho. O texto já está convertido em desenho, então não precisa instalar fonte.

## Cores

| Cor | Código | Onde |
|---|---|---|
| Roxo | `#6d28d9` | "NFC" no fundo claro, botões do sistema |
| Degradê do ícone | `#7c3aed` → `#4c1d95` | Fundo do chaveiro |
| Lilás | `#a78bfa` | "NFC" no fundo escuro |
| Preto | `#18181b` | "liente" no fundo claro |

## Fonte

Poppins (gratuita, Google Fonts): "NFC" em Bold (700) e "liente" em SemiBold (600).
